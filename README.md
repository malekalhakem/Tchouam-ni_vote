📋 About
An interactive fan voting poll for Real Madrid supporters to decide the fate of Aurélien Tchouaméni —
Should he stay or should he go?
Votes are real and persistent — every visitor sees the same live count.
The target: 200,000 "Leave" votes to send him packing.
